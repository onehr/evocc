# Archive

This directory keeps superseded plans and dated lab notes for their history. Nobody maintains
them. Nothing here is authoritative: a statement here can be out of date, and a status, a task
order or a requirement here does not apply now.

The ground truth is in [`spec/`](../../spec/README.md). The current status is in
[`docs/evidence.md`](../evidence.md), the generated [`docs/status.md`](../status.md) and
[`TODO.md`](../../TODO.md).

| Document | What it was |
|---|---|
| [`roadmap.md`](roadmap.md) | The architecture and launch plan, with dated prefaces; it also records the pins of the evaluation-ladder subjects |
| [`lean-plan.md`](lean-plan.md) | The verification plan (V00 to V08, complete); its contract is now [`spec/verification.md`](../../spec/verification.md) |
| [`codegen-quality-plan.md`](codegen-quality-plan.md) | The Q4 backend quality plan; the bounded N01 to N05 and N07 batch is closed |
| [`verified-optimization-design.md`](verified-optimization-design.md) | The design of verified optimization and of the Q2/Q3 search tracks; the implemented parts are in [`spec/evoir.md`](../../spec/evoir.md), [`spec/verification.md`](../../spec/verification.md) and the book |
| [`eqsat-guard-folding-draft.md`](eqsat-guard-folding-draft.md) | The `g0.ub.v1` guard-folding draft; implemented, and the registry is in [`spec/evoir.md`](../../spec/evoir.md) |
| [`notebook/`](notebook/) | 46 dated lab notes, ledgers, reviews and research briefs (2026-09-07 to 2026-10-04); the file name gives the topic and the date |

Tools and receipts can still name an archived path as the source of a pin or a measurement.
