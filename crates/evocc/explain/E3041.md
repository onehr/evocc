# E3041: symbol-declared-and-defined

The module gives one symbol incompatible roles, such as an alias and a separate definition.
An ordinary compatible `extern` declaration followed by a definition is not this error.

Symbol resolution must select one coherent implementation or storage object.
Keep either the alias role or the separate definition, according to the intended linkage.

```c,E3041
int value = 0;
extern int other __attribute__((alias("value")));
int other = 0;
int main(void) { return 0; }
```

```c,fixed
int value = 0;
extern int other __attribute__((alias("value")));
int main(void) { return other; }
```
