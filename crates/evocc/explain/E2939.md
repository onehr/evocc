# E2939: unsupported-wide-bit-field-promotion

An expression requires a wide bit-field promotion outside EvoCC's agreed target profile.
The field width can produce a type distinct from ordinary integer ranks.

Reference compiler behavior for these extensions is not uniform.
Use an explicit ordinary integer conversion when that is the intended arithmetic type.

```c,E2939
struct S { unsigned long x : 40; };
int main(void) { struct S s = {0}; return s.x == -1; }
```

```c,fixed
struct S { unsigned long x : 40; };
int main(void) { struct S s = {0}; return (unsigned long)s.x == -1; }
```
