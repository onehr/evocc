# E0113: directive-in-macro-argument

An unsupported directive appears while a macro argument is being collected.
EvoCC refuses to expand that argument with an unspecified directive effect.

The GNU-compatible argument collector permits only its documented directive forms.
Move a pragma outside the macro invocation so its position is explicit.

```c,E0113
#define ID(x) x
ID(int value;
#pragma GCC diagnostic push
)
int main(void) { return 0; }
```

```c,fixed
#define ID(x) x
#pragma GCC diagnostic push
ID(int value;)
int main(void) { return 0; }
```
