# E3009: null-pointer-access

The executed memory access uses a null pointer.
A null pointer does not identify storage for the requested object.

C does not permit reading or writing an object through a null pointer.
Provide a live object or handle the null case before accessing memory.

```c,E3009
int main(void) { int *p = 0; return *p; }
```

```c,fixed
int main(void) { int value = 0; int *p = &value; return *p; }
```
