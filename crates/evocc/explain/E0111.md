# E0111: conditional-operand-not-integer

A preprocessor conditional contains a number that is not an integer constant.
The preprocessor cannot evaluate it as a conditional operand.

The expression in `#if` uses integer preprocessing arithmetic.
Use an integer condition instead of a floating constant.

```c,E0111
#if 1.5
#endif
int main(void) { return 0; }
```

```c,fixed
#if 1
#endif
int main(void) { return 0; }
```
