# E0112: stray-token

The source contains a token that cannot be used at this point.
Macro expansion can also produce such a token.

Every remaining preprocessing token must have a valid C token form.
Remove the stray character or correct the macro that produced it.

```c,E0112
int main(void) { return @; }
```

```c,fixed
int main(void) { return 0; }
```
