# E3001: read-of-uninitialized-object

The executed path reads object bytes that have not been initialized.
A declaration without an initializer does not give an automatic scalar a value.

EvoCC tracks initialized bytes instead of substituting zero for missing data.
Initialize the object on every path before reading it.

```c,E3001
int main(void) { int value; return value; }
```

```c,fixed
int main(void) { int value = 0; return value; }
```
