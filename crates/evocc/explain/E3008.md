# E3008: interpreter-fuel-exhausted

The interpreter reached its execution step limit.
This is a resource limit, not proof that the program has undefined behavior.

EvoCC bounds interpreted execution so a check cannot run without limit.
Inspect long-running loops and use a finite workload when testing termination.

```c,E3008
int main(void) { for (;;) {} }
```

```c,fixed
int main(void) {
    unsigned count = 0;
    while (count < 10) ++count;
    return count != 10;
}
```

For an intentional long-running service, a step limit does not identify a source defect.
