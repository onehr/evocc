# E2002: incompatible-redeclaration

Two declarations of one name do not describe compatible entities.
The conflict can involve its type, linkage, or definition.

C requires declarations that refer to the same entity to agree.
Correct the conflicting declaration instead of casting each use.

```c,E2002
int count;
double count;
int main(void) { return 0; }
```

```c,fixed
extern int count;
int count = 0;
int main(void) { return count; }
```
