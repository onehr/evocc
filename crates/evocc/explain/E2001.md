# E2001: undeclared-identifier

The name has no declaration visible at this use.
A declaration in another scope does not make the name visible here.

C resolves an identifier using its scope and declaration.
Declare the object or function before use, and check the spelling of its name.

```c,E2001
int main(void) { return count; }
```

```c,fixed
int main(void) { int count = 0; return count; }
```
