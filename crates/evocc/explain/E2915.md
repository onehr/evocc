# E2915: auto-type-misuse

A GNU `__auto_type` declaration does not have a supported deduction form.
It needs one plain named object with an initializer.

The initializer supplies the type of the object.
Add an initializer or write the object's type explicitly.

```c,E2915
int main(void) { __auto_type value; return 0; }
```

```c,fixed
int main(void) { __auto_type value = 0; return value; }
```
