# E0110: invalid-token-paste

A macro `##` operation does not produce one preprocessing token.
The preprocessor cannot use the combined spelling as a token.

Token pasting joins spellings, not C expressions.
Use separate tokens for an arithmetic operation.

```c,E0110
#define JOIN(a, b) a ## b
int main(void) { return JOIN(1, +); }
```

```c,fixed
#define SUM(a, b) ((a) + (b))
int main(void) { return SUM(1, 2); }
```
