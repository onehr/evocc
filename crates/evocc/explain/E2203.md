# E2203: variable-length-object

A variable-length object occurs in a context that EvoCC refuses.
One such context is an initializer for a variable-length array.

In the supported C11 profile, a variable-length array cannot have an initializer.
Create the array first and assign its elements during execution.

```c,E2203
int main(void) { int n = 2; int a[n] = {1}; return 0; }
```

```c,fixed
int main(void) {
    int n = 2;
    int a[n];
    for (int i = 0; i < n; ++i) a[i] = 0;
    return a[0];
}
```
