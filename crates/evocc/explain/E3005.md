# E3005: invalid-shift-count

The shift count is negative or at least the width of the promoted left operand.
The width of the result variable does not change that operand's shift width.

C restricts the count for both left and right shifts.
Check the count before shifting instead of relying on hardware count masking.

```c,E3005
int main(void) { int count = 32; return 1U << count; }
```

```c,fixed
int main(void) {
    int count = 32;
    if (count < 0 || count >= 32) return 0;
    return (1U << count) != 0;
}
```
