# E3036: not-lowered: pointer-integer-conversion

This code is withdrawn and is never reported by the current contract.
It formerly named a pointer-to-integer or integer-to-pointer lowering limitation.

The supported conversion path retains the target's exposed-address rules.
A converted integer still needs a valid object or function target before access.

Trigger: none
Reason: the diagnostic authority table explicitly marks this code withdrawn and never reported.

An invalid pointer used for access can report E3013 instead.
