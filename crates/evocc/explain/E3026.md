# E3026: not-lowered: static-relocation

A static initializer requires a relocation expression that lowering cannot represent.
Intermediate casts can make a label difference more than a plain address subtraction.

A relocation must preserve all source conversions, including narrowing.
EvoCC refuses an unsupported form instead of dropping a cast.

```c,E3026
int main(void) {
    static long offset = (signed char)(&&end - &&start);
start:
    if (offset) goto end;
    return 0;
end:
    return 1;
}
```

Fix: none

Choose an encoding that the target relocation format can represent.
Removing the narrowing cast changes the value and is not a general fix.
