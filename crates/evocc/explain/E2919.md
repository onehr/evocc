# E2919: flexible-array-initializer-not-static

An initializer tries to provide flexible-array elements in an unsupported storage context.
EvoCC supports its flexible-array initialization extension only for static storage.

A flexible array member does not contribute ordinary elements to the struct's size.
Use a fixed-size array when an automatic object must contain initialized elements.

```c,E2919
struct Packet { int length; int data[]; };
int main(void) { struct Packet p = {1, {0}}; return 0; }
```

```c,fixed
struct Packet { int length; int data[1]; };
int main(void) { struct Packet p = {1, {0}}; return p.data[0]; }
```
