# E2913: builtin-operand-not-convertible

A builtin operand cannot meet the builtin's required type or value category.
The builtin cannot use that operand as an ordinary implicit conversion.

Builtins have specific contracts for pointers, storage, and scalar types.
Supply an operand of the required kind instead of hiding the mismatch with a cast.

```c,E2913
int main(void) { return __builtin_strlen(L"a") != 1; }
```

```c,fixed
int main(void) { return __builtin_strlen("a") != 1; }
```
