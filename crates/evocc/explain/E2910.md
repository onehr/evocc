# E2910: builtin-not-called

A special builtin appears as a value rather than a builtin invocation.
This builtin does not have an ordinary function address.

Some builtins are compiler syntax with operand-specific rules.
Invoke the builtin directly instead of storing its name as a value.

```c,E2910
int main(void) { return __builtin_constant_p; }
```

```c,fixed
int main(void) { return !__builtin_constant_p(1); }
```
