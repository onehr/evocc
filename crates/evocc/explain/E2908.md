# E2908: generic-selection-no-match

No association matches the controlling type of `_Generic`.
The selection also has no `default` association.

C requires a generic selection to produce exactly one selected expression.
Add the needed type association or a suitable default result.

```c,E2908
int main(void) { return _Generic(0, double: 1); }
```

```c,fixed
int main(void) { return _Generic(0, double: 1, int: 0); }
```
