# E2912: static-assertion-not-constant

A required integer constant expression could not be evaluated as one.
Static assertions and some builtin operands require this form.

These checks need a translation-time value, not a value read during execution.
Use an integer constant expression or move a runtime check into executable code.

```c,E2912
int limit = 4;
_Static_assert(limit > 0, "positive limit required");
int main(void) { return 0; }
```

```c,fixed
enum { limit = 4 };
_Static_assert(limit > 0, "positive limit required");
int main(void) { return 0; }
```
