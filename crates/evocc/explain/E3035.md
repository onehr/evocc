# E3035: not-lowered: global-register-variable

This withdrawn code identified missing support for global register variables.
Current lowering represents their access through implicit assembly.

Binding an object to a machine register requires target-specific behavior.
Native lowering support does not make that register available to an interpreter.

Trigger: none
Reason: the authority table withdraws this code; global register access uses implicit asm.

Use ordinary C storage when no specific machine register is required.
