# E3037: va-start-outside-variadic-signature

An IR `va_start` operation appears in a function with a nonvariadic signature.
That signature does not provide the anonymous arguments required by the operation.

The validator independently checks the IR function interface.
Fix the producer so it emits this operation only in a variadic function.

Trigger: none
Reason: the C front end rejects this source misuse with E2926 before IR validation.

E3037 remains a check on malformed IR and is distinct from a runtime argument mismatch.
