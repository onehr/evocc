# E3027: overlapping-copy

A copy operation requires disjoint source and destination ranges, but they overlap.
Different starting addresses do not prove that the complete ranges are disjoint.

The `memcpy` contract does not permit overlapping ranges.
Use `memmove` when overlap is part of the intended operation.

```c,E3027
int main(void) { char data[4] = {0}; __builtin_memcpy(data + 1, data, 3); return 0; }
```

```c,fixed
int main(void) { char data[4] = {0}; __builtin_memmove(data + 1, data, 3); return 0; }
```
