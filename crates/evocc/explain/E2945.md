# E2945: jump-into-variable-type-scope

A jump enters the scope of a variably modified declaration from outside it.
The jump would skip the declaration's required evaluation.

C forbids this entry into the scope of a variably modified identifier.
Enter the scope normally before reaching the label.

```c,E2945
int main(void) {
    int n = 2;
    goto inside;
    int values[n];
inside:
    return 0;
}
```

```c,fixed
int main(void) {
    int n = 2;
    int values[n];
    goto inside;
inside:
    return 0;
}
```
