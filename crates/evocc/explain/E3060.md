# E3060: weak-internal-symbol

A symbol combines weak binding with internal linkage.
The resulting symbol contract is not valid for this module.

Weak binding participates in external symbol resolution.
Remove weak binding from a private definition, or deliberately give the symbol external linkage.

```c,E3060
static int value __attribute__((weak));
int main(void) { return 0; }
```

```c,fixed
static int value;
int main(void) { return value; }
```
