# E2903: malformed-attribute

An attribute has invalid syntax or an invalid argument.
The diagnostic identifies the attribute EvoCC could not apply.

Attributes can change layout, linkage, or generated code.
EvoCC rejects malformed attributes instead of silently applying another meaning.

```c,E2903
typedef int Aligned __attribute__((aligned(3)));
int main(void) { return 0; }
```

```c,fixed
typedef int Aligned __attribute__((aligned(8)));
int main(void) { Aligned value = 0; return value; }
```
