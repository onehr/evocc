# E3033: not-executed: wide-integer

An operation needs an integer width outside that operation's implemented path.
Support for a type does not imply support for every use of that type.

EvoCC keeps the full width instead of silently truncating to a host integer.
Use a supported operation or provide an explicit implementation for the required width.

```c,E3033
int main(void) { asm("" : : "i"((__int128)1 << 100)); return 0; }
```

Fix: none

This example cannot encode a 128-bit immediate through the supported assembly operand path.
Narrowing it to 64 bits would lose the bit it needs.
