# E2905: statement-expression-outside-function

A GNU statement expression appears outside a function body.
The `({ ... })` form is not permitted at this position.

Statement expressions provide executable statements inside expressions.
Use a constant initializer at file scope, or move the statements into a function.

```c,E2905
int value = ({ 0; });
int main(void) { return value; }
```

```c,fixed
int value = 0;
int main(void) { return value; }
```
