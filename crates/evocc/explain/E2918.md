# E2918: jump-into-statement-expression

A jump enters a GNU statement expression from outside that expression.
This skips the normal entry and evaluation of the expression.

GNU statement expressions do not permit jumps into their bodies.
Use ordinary function-scope control flow instead of a label inside an expression.

```c,E2918
int main(void) {
    goto inside;
    ({ inside: 1; });
    return 0;
}
```

```c,fixed
int main(void) {
    goto inside;
inside:
    return 0;
}
```
