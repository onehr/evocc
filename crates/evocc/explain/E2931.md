# E2931: unprototyped-call-mismatch

Calls through an unprototyped external declaration disagree with each other.
The mismatch can involve the promoted argument types or their number.

An empty parameter list does not make arbitrary argument combinations valid.
Provide a prototype and make the calls agree with the definition.

```c,E2931
int take();
int main(void) { take(1); return take(1L); }
```

```c,fixed
int take(long value);
int main(void) { return take(1); }
int take(long value) { return value != 1; }
```
