# E2932: always-inline-cycle

Required inline expansion follows a cycle of calls.
Expanding that cycle cannot produce a finite function body.

The `always_inline` requirement cannot be satisfied by recursive expansion.
Remove the requirement or rewrite the recursion as bounded control flow.

```c,E2932
static __attribute__((always_inline)) int down(int n) {
    return n ? down(n - 1) : 0;
}
int main(void) { return down(3); }
```

```c,fixed
static int down(int n) { return n ? down(n - 1) : 0; }
int main(void) { return down(3); }
```
