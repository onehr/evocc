# E3021: not-lowered: asm

The selected execution or lowering path cannot handle this assembly statement.
Native support for an assembly form does not imply interpreter support.

Assembly can change machine state outside the interpreter's supported semantics.
EvoCC refuses the operation instead of assuming it has no effect.

```c,E3021
int main(void) { asm("nop"); return 0; }
```

```c,fixed
int main(void) { return 0; }
```

The fixed example removes a statement unnecessary for its result.
Do not remove assembly that performs required hardware or synchronization work.
