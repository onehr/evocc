# E0102: unmatched-conditional

A conditional directive has no matching opening or closing directive.
The preprocessor cannot determine which source belongs to the conditional.

Each `#if`, `#ifdef` and `#ifndef` needs one matching `#endif`.
An `#else` or `#elif` must belong to an open conditional.

```c,E0102
#endif
int main(void) { return 0; }
```

```c,fixed
#if 1
int main(void) { return 0; }
#endif
```
