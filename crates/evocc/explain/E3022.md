# E3022: bit-builtin-zero-operand

A count-leading-zeros or count-trailing-zeros builtin received zero.
These builtin forms do not define a result for that input.

EvoCC checks the builtin's source contract rather than a hardware instruction's behavior.
Handle zero before calling the builtin.

```c,E3022
int main(void) { return __builtin_clz(0); }
```

```c,fixed
int main(void) {
    unsigned value = 0;
    int leading = value == 0 ? 32 : __builtin_clz(value);
    return leading != 32;
}
```
