# E1207: invalid-return-value

The return statement does not match the function's result type.
It can supply a value to a void function or omit a required value.

C uses the declared result type to check each return statement.
Return a value of the required type, or declare a void function when appropriate.

```c,E1207
void stop(void) { return 1; }
int main(void) { stop(); return 0; }
```

```c,fixed
void stop(void) { return; }
int main(void) { stop(); return 0; }
```
