# E3061: alias-target-not-defined

A symbol alias does not resolve to a valid definition in this translation unit.
An external declaration alone does not define its target.

This alias form needs an actual target with a compatible symbol contract.
Define the target in the same translation unit and make the alias agree with it.

```c,E3061
extern int missing;
extern int other __attribute__((alias("missing")));
int main(void) { return 0; }
```

```c,fixed
int value = 0;
extern int other __attribute__((alias("value")));
int main(void) { return other; }
```
