# E0107: pragma-pack-unsupported

A `#pragma pack` request is malformed or outside the supported forms.
EvoCC refuses to guess the record layout.

Packing changes member offsets and object alignment.
Use a supported packing request and restore it after the affected declarations.

```c,E0107
#pragma pack(show)
int main(void) { return 0; }
```

```c,fixed
#pragma pack(push, 1)
struct Packet { char tag; int value; };
#pragma pack(pop)
int main(void) { return 0; }
```
