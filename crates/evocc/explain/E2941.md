# E2941: unsupported-type-classification

`__builtin_classify_type` received a type outside EvoCC's agreed classification profile.
For example, `_Bool` does not have one agreed classification in the reference compilers.

This GNU builtin reports compiler-specific type categories.
Use a direct type selection when the program needs a portable type distinction.

```c,E2941
int main(void) { return __builtin_classify_type((_Bool)0); }
```

```c,fixed
int main(void) { return _Generic((_Bool)0, _Bool: 0, default: 1); }
```
