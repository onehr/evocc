# E3015: call-through-null-function-pointer

The executed indirect call uses a null function pointer.
No function is selected by that value.

C requires a valid function target when a call is executed.
Initialize the callback or handle a missing callback before calling it.

```c,E3015
int main(void) { int (*callback)(void) = 0; return callback(); }
```

```c,fixed
int result(void) { return 0; }
int main(void) { int (*callback)(void) = result; return callback(); }
```
