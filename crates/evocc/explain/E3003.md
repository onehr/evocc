# E3003: integer-remainder-by-zero

The executed remainder operation has a zero divisor.
There is no valid integer remainder for this operation.

C does not define a remainder operation with a zero divisor.
Handle zero separately before evaluating `%`.

```c,E3003
int main(void) { int divisor = 0; return 1 % divisor; }
```

```c,fixed
int main(void) {
    int divisor = 0;
    return divisor == 0 ? 0 : 1 % divisor;
}
```
