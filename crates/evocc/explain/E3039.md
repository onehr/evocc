# E3039: external-call-not-executable

Execution reached an external call that the interpreter cannot resolve.
A declaration supplies a type, not an executable function body.

The interpreter does not call arbitrary host libraries with target arguments.
Supply a supported definition or use native compilation with the required library.

```c,E3039
extern int result(void);
int main(void) { return result(); }
```

```c,fixed
int result(void) { return 0; }
int main(void) { return result(); }
```
