# E3010: dangling-pointer-access

The pointer refers to an object whose lifetime has ended.
Keeping the address does not keep the object alive.

An access requires live storage, not just an address that was once valid.
Keep the object alive until its last use or copy its value before leaving its scope.

```c,E3010
int main(void) {
    int *p;
    { int value = 0; p = &value; }
    return *p;
}
```

```c,fixed
int main(void) {
    int result;
    { int value = 0; result = value; }
    return result;
}
```
