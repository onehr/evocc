# E2944: ordinary-builtin-binding-conflict

An ordinary name used for builtin behavior also has a conflicting source binding.
A source definition or assembly name can prevent one unambiguous binding.

Builtin expansion must not silently replace a program-defined implementation.
Give an unrelated helper a distinct name and preserve the intended call target.

```c,E2944
void *alloca(unsigned long);
int main(void) { return alloca(1) == 0; }
void *alloca(unsigned long n) { return (void *)0; }
```

```c,fixed
void *empty_buffer(unsigned long n) { return (void *)0; }
int main(void) { return empty_buffer(1) != 0; }
```
