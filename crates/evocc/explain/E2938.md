# E2938: invalid-alignment-specifier

An alignment specifier requests an invalid or disallowed alignment.
It can also try to weaken the natural alignment of an object.

C alignment requirements must remain valid for the declared type and context.
Use a supported alignment that is at least as strict as the natural alignment.

```c,E2938
_Alignas(3) int value;
int main(void) { return 0; }
```

```c,fixed
_Alignas(8) int value;
int main(void) { return value; }
```
