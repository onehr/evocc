# E3013: invalid-pointer-representation

The interpreter cannot resolve the pointer representation to a permitted target.
An arbitrary integer address is not evidence of a live object.

EvoCC's memory model keeps pointer identity and exposed-address information.
Use a pointer derived from a live object instead of inventing an address.

```c,E3013
int main(void) { return *(int *)1; }
```

```c,fixed
int main(void) { int value = 0; return *(&value); }
```

This interpreter result does not model access to a platform-specific hardware address.
