# E2943: invalid-or-conflicting-symbol-attribute

A symbol attribute or visibility directive has an invalid or conflicting setting.
EvoCC cannot apply it while preserving one consistent symbol contract.

Linkage and visibility affect how other translation units refer to a symbol.
Correct the conflicting settings or balance the visibility directive stack.

```c,E2943
#pragma GCC visibility pop
int main(void) { return 0; }
```

```c,fixed
#pragma GCC visibility push(hidden)
int helper(void) { return 0; }
#pragma GCC visibility pop
int main(void) { return helper(); }
```
