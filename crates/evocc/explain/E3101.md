# E3101: evoir-lowering-failed

Lowering could not construct valid EvoIR for this source.
The detail after the header identifies the failed operation or validation rule.

EvoCC checks generated IR instead of executing an inconsistent module.
Reduce unexpected failures to a small source example and report them with the full diagnostic.

```c,E3101
int main(void) { goto *(void *)1; }
```

```c,fixed
int main(void) { void *target = &&done; goto *target; done: return 0; }
```

This example has no valid label target; the fix supplies one.
Other lowering failures can be compiler defects rather than source errors.
