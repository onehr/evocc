# E3011: out-of-bounds-memory-access

The executed access extends outside the object's permitted storage.
A one-past pointer can describe an endpoint but cannot be dereferenced.

C accesses must stay within the applicable object bounds.
Check indices and access sizes before reading or writing.

```c,E3011
int main(void) { int values[2] = {0}; return values[2]; }
```

```c,fixed
int main(void) { int values[2] = {0}; return values[1]; }
```
