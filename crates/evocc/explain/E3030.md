# E3030: not-lowered: varargs

A variadic operation requires a type or ABI form outside the supported path.
This does not mean that all variadic calls are unsupported.

Each anonymous argument must be passed and retrieved using its real ABI classification.
EvoCC refuses unsupported forms instead of assigning them an unrelated scalar layout.

```c,E3030
struct S { __fp16 half; int tag; };
int take(int n, ...) {
    __builtin_va_list ap;
    __builtin_va_start(ap, n);
    struct S value = __builtin_va_arg(ap, struct S);
    return 0;
}
int main(void) { return 0; }
```

Fix: none

Use an implemented interface that preserves the required data and calling contract.
Replacing the argument type with `double` does not preserve this interface.
