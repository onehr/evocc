# E3047: builtin-trap-reached

Execution reached `__builtin_trap()`.
The program explicitly requested abnormal termination at this point.

The interpreter reports the trap instead of terminating its own host process.
Inspect the condition that selected this path before changing the trap.

```c,E3047
int main(void) { __builtin_trap(); }
```

```c,fixed
int main(void) { int valid = 1; if (!valid) __builtin_trap(); return 0; }
```
