# E2936: invalid-line-directive

A `#line` directive has an invalid line number or operand form.
EvoCC cannot use it to set the following source location.

Line directives control the locations reported for subsequent source text.
Supply a valid positive line number and an optional quoted filename.

```c,E2936
#line nope
int main(void) { return 0; }
```

```c,fixed
#line 1 "example.c"
int main(void) { return 0; }
```
