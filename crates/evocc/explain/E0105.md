# E0105: include-not-found

The preprocessor cannot find the requested header.
The include search paths do not contain a readable matching file.

A source file cannot use declarations from a header that was not read.
Install the header or correct its name and include path.

```c,E0105
#include "evocc-example-missing-header.h"
int main(void) { return 0; }
```

For this self-contained program, no header is needed.

```c,fixed
int main(void) { return 0; }
```
