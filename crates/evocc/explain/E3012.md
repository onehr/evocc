# E3012: misaligned-memory-access

The pointer is not aligned for the executed access.
A cast changes the pointer type but does not align the address.

C typed accesses must meet the required alignment.
Use aligned storage or copy bytes into an aligned object before a typed read.

```c,E3012
int main(void) {
    int values[2] = {0};
    char *p = (char *)values;
    return *(int *)(p + 1);
}
```

```c,fixed
int main(void) { int values[2] = {0}; return values[1]; }
```
