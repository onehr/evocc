# E2928: address-of-register-object

The address operator is applied to an object declared `register`.
The restriction applies even when the compiler stores the object in memory.

C forbids taking the address of a register-declared object.
Remove `register` when the program needs the object's address.

```c,E2928
int main(void) { register int value = 0; int *p = &value; return *p; }
```

```c,fixed
int main(void) { int value = 0; int *p = &value; return *p; }
```
