# E3019: function-pointer-target-signature-mismatch

The executed function pointer selects a function with an incompatible signature.
The pointer's declared call interface does not match that function's actual interface.

C does not permit calling a function through an incompatible function type.
Keep the pointer type consistent with the function definition.

```c,E3019
long result(long value) { return value; }
int main(void) {
    int (*callback)(int) = (int (*)(int))result;
    return callback(0);
}
```

```c,fixed
long result(long value) { return value; }
int main(void) { long (*callback)(long) = result; return callback(0); }
```
