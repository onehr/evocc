# E2916: case-range-invalid

A switch case or GNU case range cannot form a valid set of case values.
The bounds must be constant and must not conflict with another case.

A switch must select an unambiguous destination for each matching value.
Correct the bounds and remove overlapping or duplicate cases.

```c,E2916
int main(void) {
    switch (2) { case 3 ... 1: return 1; default: return 0; }
}
```

```c,fixed
int main(void) {
    switch (2) { case 1 ... 3: return 0; default: return 1; }
}
```
