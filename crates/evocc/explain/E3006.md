# E3006: invalid-signed-left-shift

This code names an explicit IR obligation for a signed left shift.
The current GNU source profile does not insert that obligation.

For a valid count, this profile defines the result as the low bits of the product.
It still checks the count and reports E3005 when the count is invalid.

Trigger: none
Reason: C lowering does not assert signed_shl_defined in the current GNU profile.

The code remains readable for explicit IR obligations.
Do not treat a negative left operand alone as an E3006 source trigger.
