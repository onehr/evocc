# E2922: volatile-aggregate-copy-unsupported

A volatile aggregate copy requires an access pattern EvoCC does not support.
Examples include oversized unions and records with bit-fields.

Volatile accesses have observable behavior that a byte copy can change.
EvoCC refuses the copy instead of inventing an access width or order.

```c,E2922
union U { int narrow; long wide[2]; };
void copy(volatile union U *to, volatile union U *from) { *to = *from; }
int main(void) { return 0; }
```

Fix: none

Specify the required hardware access operations before replacing this copy.
Removing `volatile` is not a general fix.
