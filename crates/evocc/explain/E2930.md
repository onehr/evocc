# E2930: use-with-incomplete-enumeration

An expression requires an enumeration type that is still incomplete.
A forward declaration alone does not supply its completed type information.

EvoCC needs the completed type to validate values and function interfaces.
Define the enumeration before a use that needs that information.

```c,E2930
enum Result;
enum Result result(void);
int main(void) { return result(); }
```

```c,fixed
enum Result { OK = 0 };
enum Result result(void) { return OK; }
int main(void) { return result(); }
```
