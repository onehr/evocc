# E3023: not-lowered: bit-builtin

This withdrawn code identified missing lowering for bit builtins.
Current supported bit builtins do not use this refusal.

The implementation now lowers those operations with their operand requirements.
For a zero operand to a restricted count builtin, handle the input or expect E3022.

Trigger: none
Reason: the diagnostic authority table marks this lowering refusal as withdrawn.

```c,fixed
int main(void) { return __builtin_popcount(3U) != 2; }
```
