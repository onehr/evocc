# E1005: invalid-declarator

This declaration combines type constructors in an invalid order.
For example, it can declare an array of functions instead of function pointers.

C permits arrays of objects, but a function is not an object.
Declare pointers when an array must refer to functions.

```c,E1005
int handlers[2](int argument);
int main(void) { return 0; }
```

```c,fixed
int (*handlers[2])(int argument);
int main(void) { return 0; }
```
