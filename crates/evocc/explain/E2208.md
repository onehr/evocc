# E2208: non-constant-static-initializer

A static-storage initializer requires a value that is not constant at translation.
Calling a function in that initializer is one example.

C requires static-storage initialization to use permitted constant expressions.
Move the computation into a function that runs before the value is used.

```c,E2208
int initial(void) { return 0; }
static int value = initial();
int main(void) { return value; }
```

```c,fixed
int initial(void) { return 0; }
static int value;
int main(void) { value = initial(); return value; }
```
