# E2926: va-start-outside-variadic-function

`__builtin_va_start` appears outside a variadic function.
There is no unnamed argument sequence for it to initialize.

A variadic argument cursor belongs to the current variadic invocation.
Use it only in a function whose declaration ends with `...`.

```c,E2926
int main(void) {
    __builtin_va_list ap;
    __builtin_va_start(ap, 0);
    return 0;
}
```

```c,fixed
int first(int count, ...) {
    __builtin_va_list ap;
    __builtin_va_start(ap, count);
    int value = __builtin_va_arg(ap, int);
    __builtin_va_end(ap);
    return value;
}
int main(void) { return first(1, 0); }
```
