# E2920: undeclared-label

A branch refers to a label that has no definition in the function.
A label in another function does not satisfy this reference.

C labels have function scope and must name destinations in that function.
Correct the label name or add the intended destination.

```c,E2920
int main(void) { goto done; }
```

```c,fixed
int main(void) { goto done; done: return 0; }
```
