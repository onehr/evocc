# E2907: generic-selection-duplicate-association

A `_Generic` selection has two associations with compatible types.
More than one `default` association also causes this diagnostic.

C requires a generic selection to identify at most one matching association.
Remove the duplicate and keep one result for each compatible type.

```c,E2907
int main(void) { return _Generic(0, int: 0, int: 1); }
```

```c,fixed
int main(void) { return _Generic(0, int: 0, default: 1); }
```
