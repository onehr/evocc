# E2909: builtin-arity

A builtin has the wrong number of operands.
Each recognized builtin has a fixed operand contract.

EvoCC needs every required operand to apply the builtin's semantics.
Use the documented operand count instead of relying on ordinary variadic calls.

```c,E2909
int main(void) { return __builtin_expect(0); }
```

```c,fixed
int main(void) { return __builtin_expect(0, 0); }
```
