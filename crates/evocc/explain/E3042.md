# E3042: not-lowered: checked-arithmetic-width

This withdrawn code identified a checked-arithmetic width limitation.
It must not be reused for a new unsupported operation.

Current supported arithmetic paths retain their actual operand width and overflow checks.
A supported operation that overflows has a runtime diagnostic, not this old lowering refusal.

Trigger: none
Reason: the diagnostic authority table marks this lowering refusal as withdrawn.

```c,fixed
int main(void) { long value = 1; return value + 1 != 2; }
```
