# E3038: va-arg-mismatch

The variadic cursor cannot supply an argument of the requested type.
It can also have reached the end of the supplied arguments.

C requires each variadic read to agree with the corresponding promoted argument.
Keep the caller's types, the argument count, and the callee's reads consistent.

```c,E3038
int first(int n, ...) {
    __builtin_va_list ap;
    __builtin_va_start(ap, n);
    return __builtin_va_arg(ap, long);
}
int main(void) { return first(1, 0); }
```

```c,fixed
int first(int n, ...) {
    __builtin_va_list ap;
    __builtin_va_start(ap, n);
    int result = __builtin_va_arg(ap, int);
    __builtin_va_end(ap);
    return result;
}
int main(void) { return first(1, 0); }
```
