# E0106: feature-query-malformed

A feature query has invalid arguments or missing punctuation.
The preprocessor cannot evaluate the query.

Each query has a specific argument form.
For example, `__has_attribute` takes one attribute name in parentheses.

```c,E0106
#if __has_attribute()
#endif
int main(void) { return 0; }
```

```c,fixed
#if __has_attribute(unused)
#define UNUSED __attribute__((unused))
#else
#define UNUSED
#endif
int main(void) { return 0; }
```
