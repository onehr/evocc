# E0104: error-directive

The preprocessor reached an active `#error` directive.
The text after the directive describes the source author's requirement.

This directive deliberately stops translation when a source condition is not met.
Correct the configuration instead of removing a required check.

```c,E0104
#ifndef BUFFER_SIZE
#error define BUFFER_SIZE before this point
#endif
int main(void) { return 0; }
```

```c,fixed
#define BUFFER_SIZE 64
#ifndef BUFFER_SIZE
#error define BUFFER_SIZE before this point
#endif
int main(void) { return 0; }
```
