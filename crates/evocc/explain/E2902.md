# E2902: not-covered: compound-literal

This withdrawn code identified unsupported compound literals.
Current EvoCC lowers compound literals and must not reuse this code.

A compound literal creates an unnamed object with an initializer.
The implementation now tracks that object's storage and lifetime.

Trigger: none
Reason: the diagnostic authority table marks this code as withdrawn.

```c,fixed
struct Pair { int x, y; };
int main(void) {
    struct Pair pair = (struct Pair){0, 1};
    return pair.x;
}
```
