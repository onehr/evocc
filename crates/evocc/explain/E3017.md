# E3017: indirect-call-signature-mismatch

An IR indirect call disagrees with the function-pointer type at the call site.
This is a malformed call interface, not a runtime selection of the wrong function.

The validator checks the call arguments and results against that pointer type.
Fix the IR producer so the instruction uses the declared interface.

Trigger: none
Reason: this validator diagnostic needs malformed IR, not a well-formed C call.

For a C cast that selects an incompatible function at runtime, see E3019.
