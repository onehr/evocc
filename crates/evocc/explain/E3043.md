# E3043: not-lowered: object-function-pointer-conversion

This withdrawn code identified an object-pointer and function-pointer conversion limitation.
It does not describe a runtime call through an invalid function target.

A permitted conversion does not establish that the converted pointer can be called.
Use the correct pointer kind and preserve the identity of the actual target.

Trigger: none
Reason: the diagnostic authority table marks this lowering refusal as withdrawn.

A call through data storage reports E3016 on the executed path.
