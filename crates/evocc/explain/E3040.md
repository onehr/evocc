# E3040: external-object-not-executable

Execution needs an external object whose storage is not available to the interpreter.
An `extern` declaration alone does not allocate that object.

A native linker can resolve another translation unit, but this execution lacks its storage.
Provide the object's definition or test the linked native program instead.

```c,E3040
extern int value;
int main(void) { return value; }
```

```c,fixed
int value = 0;
int main(void) { return value; }
```
