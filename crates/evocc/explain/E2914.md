# E2914: malformed-asm

An assembly declaration has invalid syntax or invalid operands.
For example, an output constraint can name an expression that is not writable.

The compiler must know where assembly reads and writes values.
Correct the operands and constraints before asking the backend to emit assembly.

```c,E2914
int main(void) { asm("" : "=r"(1)); return 0; }
```

```c,fixed
int main(void) { int value = 0; return value; }
```

The fixed example removes an unnecessary assembly statement.
The interpreter does not execute arbitrary machine assembly.
