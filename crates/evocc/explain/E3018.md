# E3018: invalid-lifetime-end

The contract assigns this code to an invalid explicit end of an object's lifetime.
The object must be automatic storage owned by the current frame at its base address.

An IR lifetime operation must not destroy a foreign frame or static object.
Correct the producer of the lifetime operation rather than suppressing the check.

Trigger: none
Reason: C has no explicit lifetime.end operation, and the memory diagnostic currently uses E3007.

That code mapping differs from the authority table and needs a separate correction.
An ordinary use after scope exit instead reports E3010.
