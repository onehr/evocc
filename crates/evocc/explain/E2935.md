# E2935: unsupported-library-builtin

This library builtin is outside the selected EvoCC front-end profile.
EvoCC does not silently replace it with an operation of different behavior.

Library calls can have output, error, and environment effects.
A replacement must preserve those effects, not just the return type.

```c,E2935
int main(void) { return __builtin_puts("hello"); }
```

Fix: none

Use the library's ordinary declared interface for native compilation.
That does not establish interpreter support for the external call.
