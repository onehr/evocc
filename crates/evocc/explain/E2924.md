# E2924: attribute-on-non-null-statement

A statement attribute appears before a statement that is not a null statement.
EvoCC requires this attribute form to end with a semicolon.

An attribute's placement determines which entity it affects.
Put the attribute on a permitted statement instead of treating it as a prefix.

```c,E2924
int main(void) { __attribute__((unused)) return 0; }
```

```c,fixed
int main(void) { return 0; }
```

The fixed example removes an attribute with no useful statement target.
