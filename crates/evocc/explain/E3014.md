# E3014: write-to-read-only-object

The executed store writes an object marked read-only.
A pointer cast does not change that object's storage permission.

C does not permit modifying a string literal or a const-defined object this way.
Use a writable copy when the program needs to change the data.

```c,E3014
int main(void) { char *text = "abc"; text[0] = 0; return 0; }
```

```c,fixed
int main(void) { char text[] = "abc"; text[0] = 0; return text[0]; }
```
