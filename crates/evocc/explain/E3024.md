# E3024: unreachable-reached

Execution reached `__builtin_unreachable()`.
The program's assertion that this path cannot execute was false.

This builtin is not a runtime check with a recovery path.
Handle the reachable case explicitly instead of declaring it impossible.

```c,E3024
int main(void) { __builtin_unreachable(); }
```

```c,fixed
int main(void) { return 0; }
```
