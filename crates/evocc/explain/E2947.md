# E2947: invalid-atomic-memory-order

An atomic builtin has an invalid memory-order operand.
An order can be valid for one operation but invalid for another.

For example, a load cannot provide release ordering.
Choose an order permitted by the operation and sufficient for the synchronization protocol.

```c,E2947
int main(void) { int value = 0; return __atomic_load_n(&value, 3); }
```

```c,fixed
int main(void) { int value = 0; return __atomic_load_n(&value, 2); }
```

The example changes release (3) to acquire (2).
The required order in a concurrent program depends on its communication protocol.
