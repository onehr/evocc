# E2923: invalid-array-bound

An array declaration has an invalid bound.
A negative constant bound cannot describe an array object.

C array bounds must satisfy the requirements for their declaration context.
Use a valid size and check runtime sizes before creating variable-length arrays.

```c,E2923
int values[-1];
int main(void) { return 0; }
```

```c,fixed
int values[1];
int main(void) { return values[0]; }
```
