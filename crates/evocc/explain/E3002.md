# E3002: integer-division-by-zero

The executed integer division has a zero divisor.
The numerator does not make this operation valid, even when it is zero.

C does not define integer division by zero.
Check the divisor and choose the required error behavior before dividing.

```c,E3002
int main(void) { int divisor = 0; return 1 / divisor; }
```

```c,fixed
int main(void) {
    int divisor = 0;
    if (divisor == 0) return 0;
    return 1 / divisor;
}
```
