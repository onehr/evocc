# E3029: not-lowered: computed-goto

This former refusal applied to computed-goto lowering.
It is withdrawn for the supported `br.indirect` representation.

A computed goto must still identify a valid destination in its function.
An invalid executed target is a different finding, E3048.

Trigger: none
Reason: supported C computed gotos now use br.indirect rather than this refusal.

```c,fixed
int main(void) { void *target = &&done; goto *target; done: return 0; }
```
