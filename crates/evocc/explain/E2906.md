# E2906: designator-outside-object

A member or element designator does not select part of the specified object.
This also applies to a member path in `__builtin_offsetof`.

C layout queries and designated initializers need a valid subobject.
Use a member or index that exists in the declared type.

```c,E2906
struct Item { int value; };
unsigned long offset = __builtin_offsetof(struct Item, missing);
int main(void) { return 0; }
```

```c,fixed
struct Item { int value; };
unsigned long offset = __builtin_offsetof(struct Item, value);
int main(void) { return offset != 0; }
```
