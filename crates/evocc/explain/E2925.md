# E2925: builtin-mode-out-of-range

A builtin mode operand is outside the supported range.
For `__builtin_object_size`, the mode must be an integer constant from 0 to 3.

The mode selects distinct rules for the object-size query.
Choose the mode that describes the required query rather than an arbitrary integer.

```c,E2925
int main(void) { char a[4]; return __builtin_object_size(a, 4) != 4; }
```

```c,fixed
int main(void) { char a[4]; return __builtin_object_size(a, 0) != 4; }
```
