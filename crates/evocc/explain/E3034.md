# E3034: not-lowered: function-pointer-arithmetic

This withdrawn code identified a former function-pointer arithmetic refusal.
The GNU target profile now uses exposed addresses for the supported operations.

This extension is not a portable ISO C function-pointer arithmetic guarantee.
Prefer an actual function pointer when selecting a function to call.

Trigger: none
Reason: the authority table withdraws this refusal in favor of exposed-address lowering.

```c,fixed
int result(void) { return 0; }
int main(void) { int (*p)(void) = result; return p(); }
```
