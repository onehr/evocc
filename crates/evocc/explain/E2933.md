# E2933: unsupported-termination-builtin

EvoCC refuses this termination builtin in the selected front-end profile.
The refusal does not mean that ordinary return statements are unsupported.

Process termination has effects beyond returning from an ordinary function.
EvoCC does not substitute an incomplete execution model for those effects.

```c,E2933
int main(void) { __builtin_exit(0); }
```

```c,fixed
int main(void) { return 0; }
```

Returning from `main` suffices for this example.
It is not a replacement for terminating a process from an arbitrary function.
