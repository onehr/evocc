# E3048: invalid-indirect-branch-target

An executed computed goto does not identify a valid destination in its function.
Changing a label address numerically can destroy its target identity.

The interpreter checks the runtime address against the function's allowed destinations.
Keep an original label value instead of constructing an arbitrary branch address.

```c,E3048
int main(void) {
    void *target = &&done;
    unsigned long address = (unsigned long)target;
    target = (void *)(address + 1);
    goto *target;
done:
    return 0;
}
```

```c,fixed
int main(void) { void *target = &&done; goto *target; done: return 0; }
```
