# E3045: not-lowered: ordered-pointer-comparison

This withdrawn code identified missing ordered pointer comparison lowering.
Supported pointer comparisons now have an implemented path.

An implemented comparison does not remove C's restrictions on comparable pointers.
Use pointers within the relationships permitted by the source and target profile.

Trigger: none
Reason: the diagnostic authority table marks this lowering refusal as withdrawn.

```c,fixed
int main(void) { int values[2]; return !(&values[0] < &values[1]); }
```
