# E2911: static-assertion-failed

A `_Static_assert` condition evaluated to zero.
The message supplied by the source describes the condition that must hold.

C checks static assertions during translation, not during program execution.
Correct the violated requirement and keep a useful assertion for that requirement.

```c,E2911
_Static_assert(sizeof(char) == 2, "one byte required");
int main(void) { return 0; }
```

```c,fixed
_Static_assert(sizeof(char) == 1, "one byte required");
int main(void) { return 0; }
```
