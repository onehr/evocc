# E2927: builtin-library-declaration-incompatible

A library declaration conflicts with the interface required by a builtin.
EvoCC cannot bind the builtin to a function of that type.

Builtin expansion must preserve the library function's calling interface.
Use the correct declaration, normally from the library's header.

```c,E2927
int strlen(int);
unsigned long size(char *p) { return __builtin_strlen(p); }
int main(void) { return 0; }
```

```c,fixed
unsigned long strlen(const char *);
int main(void) { return __builtin_strlen("a") != 1; }
```
