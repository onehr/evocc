# E3016: call-through-non-function-pointer

The indirect call's pointer identifies data rather than a function.
Changing the pointer's type does not turn object storage into executable code.

The interpreter distinguishes object addresses from function identities.
Pass a real function pointer with the required signature.

```c,E3016
int main(void) {
    int object = 0;
    int (*callback)(void) = (int (*)(void))&object;
    return callback();
}
```

```c,fixed
int result(void) { return 0; }
int main(void) { int (*callback)(void) = result; return callback(); }
```
