# E2929: unpromoted-va-arg-type

`__builtin_va_arg` requests a type changed by default argument promotion.
For example, an anonymous `char` argument arrives as `int`, not `char`.

C promotes narrow integers and promotes `float` to `double` in variadic calls.
Read the promoted type, then convert the value if a narrower type is needed.

```c,E2929
int first(int n, ...) {
    __builtin_va_list ap;
    __builtin_va_start(ap, n);
    return __builtin_va_arg(ap, char);
}
int main(void) { return first(1, 0); }
```

```c,fixed
int first(int n, ...) {
    __builtin_va_list ap;
    __builtin_va_start(ap, n);
    int value = __builtin_va_arg(ap, int);
    __builtin_va_end(ap);
    return value;
}
int main(void) { return first(1, 0); }
```
