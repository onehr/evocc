# E2937: invalid-call-target

The expression before a call's parentheses is not callable.
An integer object is not a function or a function pointer.

C function calls require a function designator or a pointer to a function.
Call the intended function instead of a variable with a similar name.

```c,E2937
int main(void) { int result = 0; return result(); }
```

```c,fixed
int result(void) { return 0; }
int main(void) { return result(); }
```
