# E3025: not-lowered: return-address

The contract reserves this code for unsupported return-address lowering.
It describes a target capability limit rather than an ordinary integer result.

An ancestor's return address depends on machine frames and calling conventions.
EvoCC must not invent that address when the requested level is unsupported.

Trigger: none
Reason: the current front end rejects nonzero return-address levels with E2913 before lowering.

Pass the required caller information explicitly instead of inspecting its return address.
