# E2934: function-specifier-on-non-function

A function specifier is attached to something other than a permitted function declaration.
For example, `_Noreturn` cannot describe an integer object.

Function specifiers describe function behavior, not object storage.
Remove the specifier from the object declaration.

```c,E2934
_Noreturn int value;
int main(void) { return 0; }
```

```c,fixed
int value;
int main(void) { return value; }
```
