# E0109: counter-overflow

The diagnostic contract assigns this code to exhaustion of `__COUNTER__`.
The specified limit is 2^32 expansions in one translation unit.

Reusing counter values can break generated names that must be distinct.
This is an EvoCC extension limit, not an ISO C integer expression rule.

Trigger: none
Reason: the current preprocessor wraps its u32 counter and does not emit this code.

This is a known difference between the implementation and the diagnostic contract.
There is no tested C trigger or compiler-side fix in this explanation package.
Reduce generated expansions or split the translation unit before that limit.
