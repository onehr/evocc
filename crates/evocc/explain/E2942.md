# E2942: incompatible-union-cast

A GNU cast to a union has no compatible member for the operand.
The cast cannot select a valid union member to initialize.

This extension selects a member by type, not by a byte reinterpretation of arbitrary data.
Use a compatible member value or an explicit member initializer.

```c,E2942
union Number { int value; };
int main(void) { union Number n = (union Number)1.5; return 0; }
```

```c,fixed
union Number { int value; };
int main(void) { union Number n = {.value = 0}; return n.value; }
```
