# E0108: poisoned-identifier-used

The preprocessor found a use of an identifier marked with `#pragma GCC poison`.
That directive forbids later direct uses of the name.

Headers can use poisoning to reject an obsolete interface.
Replace the forbidden name with the permitted interface.

```c,E0108
#pragma GCC poison obsolete
int main(void) { int obsolete = 0; return obsolete; }
```

```c,fixed
#pragma GCC poison obsolete
int main(void) { int current = 0; return current; }
```
